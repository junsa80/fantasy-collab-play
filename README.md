# fantasy-collab-play

Public **web play** build for [junsa80/fantasy-collab](https://github.com/junsa80/fantasy-collab) (private source).

- Game: 환상 콜라보 JRPG (Musou Orochi–style mashup)
- Engine: Godot 4.7 HTML5 export
- Source license: MIT (upstream framework [kuryart/godot-jrpg](https://github.com/kuryart/godot-jrpg); see `LICENSE` and credits in the private repo)
- Owner of game code: **SRPG 개발봇**. This repo only hosts the exported `docs/` runtime for GitHub Pages.

## Play

After the first export is published: **https://junsa80.github.io/fantasy-collab-play/**

## Layout

- `docs/` — Godot web export (`index.html`, `.wasm`, `.pck`, …) for Pages (`main` / `docs`)
- Until an export lands, `docs/index.html` is a placeholder.

Characters and stories are **safe game materials only** (adults fully clothed). No erotica.
